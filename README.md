joshmanela.me source code
============

This repository represents the source code to the website joshmanela.me. It's based on the [jekyll/minima](https://github.com/jekyll/minima) template.

Local development
-----------------

```sh
scripts/bootstrap    # once, per machine — installs ruby and the gems
scripts/server       # preview at http://localhost:4000 with live reload
scripts/doctor       # when something is broken, run this first
```

See [scripts/README.md](scripts/README.md) for the full set.
